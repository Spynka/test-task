Визуал

  • Убран плейсхолдер {_offer_value:vit} - для того, чтобы мусорный код в конце HTML не попадал на страницу и не ломал отображение.
  • Закомментирован проблемный скрипт (строка 112) - для того, чтобы он не мешал работе формы и трекинга.
  • Переопределён шрифт - для того, чтобы дать странице читаемый вид.
  • Добавлены скруглённые края у фото и GIF - для того, чтобы страница выглядела аккуратнее и современнее.
  • Увеличены отступы между абзацами - для того, чтобы длинный текст читался легче.
  • Выстроена иерархия размеров текста - для того, чтобы заголовок доминировал, а текст не «сливался».
  • Добавлен адаптив для десктопа - для того, чтобы на больших экранах текст не был зажат в узкую полосу.
  • Добавлен липкий хедер с логотипом и кнопкой «Связаться/Contactar» - для того, чтобы обеспечить быстрый доступ к форме с любого места страницы.
  • Добавлена подсветка полей при переходе к форме - для того, чтобы пользователь видел визуальный ориентир, куда вводить данные.
  • Добавлен clear: both для GIF - для того, чтобы убрать наложение и «обтекание» блоков друг на друга.
  • Убран горизонтальный скролл на мобильных - для того, чтобы страница не «ёрзала» вбок.
  • Комментарии переверстаны на flexbox - для того, чтобы на мобильном отображались все отзывы, а не только один.
  • Кнопки и поля ввода получили скругление, тени и focus - для того, чтобы иметь единый стиль с остальной страницей.
  • Блок цены переверстан (гибкий flex, старая цена перечёркнута) - для того, чтобы он не читался как «каша» из цифр.
  • Блок заказа получил фон, тень и рамку - для того, чтобы выделиться.
  • Добавлен блок контактов (email, WhatsApp) - для того, чтобы усилить доверие и дать альтернативный канал связи.
  • Добавлена кнопка языка RU/ES внизу экрана - для того, чтобы переключать язык без перезагрузки страницы.
